# GenAI 기초 1: LLM 기반 업무 자동화 — 교육 과정 수강 문의 답변 초안 작성

"LLM 기반 업무 자동화" 미션 결과물 저장소입니다.
하나의 업무 과업(**교육 과정 수강 문의에 대한 고객 응대 답변 초안 작성**)을 정의하고,
3종 LLM을 평가 축 기반으로 비교해 모델을 선정한 뒤,
시스템 프롬프트·입력 템플릿·Few-shot·단계적 추론 유도·환각 검증·10턴 이상 대화 검증까지 진행했습니다.

## 선택한 업무 과업 (한 줄 요약)

| 항목 | 내용 |
|---|---|
| 과업 | 교육 과정 수강 문의(일정·비용·환불·수료 조건 등)에 대한 **답변 초안** 작성 |
| 타겟 사용자 | 교육 운영팀 CS 담당자 / 과정 운영 매니저 |
| 입력 | 고객 문의 원문 + 해당 과정의 **정책 정보 블록**(과정명, 일정, 수강료, 환불 규정, 수료 기준 등) + 응대 채널/톤 |
| 출력 | `[문의 요약] / [답변 초안] / [확인 필요 항목]` 3단 구성 |
| 최종 선정 모델 | **Claude** (가중 총점 4.58 / 5) |

## 주요 학습 내용

- LLM은 사실을 "조회"하지 않고 다음 토큰을 확률적으로 생성한다. 그래서 정책 정보가 입력에 없으면
  그럴듯한 수치(환불 비율, 기한 등)를 만들어낼 수 있다 → **정책 정보는 반드시 입력으로 주입**하고,
  입력에 없는 사실은 `[확인 필요]`로 남기도록 설계했다.
- 시스템 프롬프트(역할·규칙) / 유저 프롬프트(이번 요청) / 입력 템플릿(데이터 슬롯)을 분리하면
  규칙은 고정하고 데이터만 바꿔 재사용할 수 있다.
- 모델 비교는 "느낌"이 아니라 과업 특성에서 도출한 평가 축(정책 충실도, 환각 억제 등)과 가중치로 판단해야 한다.
- 긴 대화에서는 "현재 확정 조건 요약" 블록을 매 응답에 갱신하는 방식이 문맥 유지에 효과적이었다.
